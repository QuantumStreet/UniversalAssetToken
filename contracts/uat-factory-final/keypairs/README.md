### `../target/deploy/uat_factory-keypair.json`
- **Type**: Solana program keypair (compiled)
- **Program ID**: `69nVV8kMbkz8i2qKMPYeMxdwNdZDdFpUGjADLh3oahsB`
- **Purpose**: The program account keypair for deploying UAT Factory contract
- **Generated by**: Anchor build process
- **Security**: ⚠️ Keep private, determines the program's on-chain address

## Important Notes

1. **Never share private keys publicly**
2. **Back up these files securely**
3. **The program keypair determines your contract's on-chain address**
4. **If you lose the program keypair, you cannot upgrade the deployed program**

## Solana Playground Deployment

When deploying via Solana Playground:
- You can use **either** a Playground-generated program keypair
- **Or** import the existing `uat_factory-keypair.json` to maintain the Program ID

The wallet keypair (`solana-playground-wallet.json`) is separate and used for paying deployment fees.
