## 📋 Required Supporting Documents

### 1. **Title Document** ✅ REQUIRED
- **Description:** Deed, warranty deed, or other title document
- **Purpose:** Proves legal ownership of the property
- **Format:** PDF, DOC, DOCX
- **Requirements:**
  - Must show clear chain of title
  - Property description must match
  - Current owner must be Settlor
  - No liens or encumbrances (or disclosed)

### 2. **Appraisal Document** ✅ REQUIRED
- **Description:** Third-party professional appraisal
- **Purpose:** Validates property value (minimum $25M for AAA+)
- **Format:** PDF, DOC, DOCX
- **Requirements:**
  - Must be from licensed appraiser
  - Dated within last 6 months
  - Fair market value clearly stated
  - Comparable properties included

### 3. **Insurance Document** ✅ REQUIRED
- **Description:** Property insurance policy
- **Purpose:** Protects trust asset
- **Format:** PDF, DOC, DOCX
- **Requirements:**
  - Coverage amount must match property value
  - Trust must be named insured or loss payee
  - Policy must be current and active
  - Includes liability coverage

### 4. **Survey Document** ⚠️ OPTIONAL (Recommended)
- **Description:** Property survey and boundary information
- **Purpose:** Confirms square footage and boundaries
- **Format:** PDF, DOC, DOCX
- **Requirements:**
  - Professional surveyor
  - Shows property boundaries
  - Square footage calculations
  - Structures identified

## 🏛️ AAA+ Trust Key Provisions

### Property Requirements
- **Minimum Value:** $25,000,000 per property
- **Property Type:** Single Family Residential (AAA grade)
- **Tokenization:** 1 token = 1 square foot (property + structures)
- **Duration:** 1,000 years (Wyoming perpetuity period)

### Token Structure
- **Token Name:** FH001-SFR-RPT-NFT
- **Naming Convention:** FH001-SFR-RPT-NFT-{ADDRESS}-{SQFT}
- **Fixed Supply:** Cannot increase/decrease after initial disposition
- **Blockchain:** Solana (with migration provisions)

### Financial Terms
- **Annual Distribution:** 100% of NET profits to beneficiaries
- **Reserve Fund:** 10% of NET profits allocated to reserve
- **Trustee Fee:** Based on fair market value appraisal
- **No Co-mingling:** Each property treated as separate silo

### Beneficiary Rights
- **No Occupancy:** Beneficiaries cannot occupy properties
- **Limited Visitation:** 30%+ token holders get 3 days/year
- **No Governance:** Beneficiaries have no decision-making authority
- **Annual Distributions:** Equal per token per property

## 🎯 AAA+ Trust Naming Convention

For property tokenization, the trust name follows:

```
FH001-SFR-RPT-NFT-{STREET-NUMBER}-{STREET-NAME}-{ZIP}-{SQFT}

Example:
FH001-SFR-RPT-NFT-1700-S-FALL-CREEK-RD-83014-3116208
```

Where:
- **FH001** = Fractional Holders series 001
- **SFR** = Single Family Residential
- **RPT** = Real Property Token
- **NFT** = Non-Fungible Token
- **1700** = Street number
- **S-FALL-CREEK-RD** = Street name
- **83014** = ZIP code
- **3116208** = Total square footage

This is auto-generated by the wizard based on property address and square footage.
